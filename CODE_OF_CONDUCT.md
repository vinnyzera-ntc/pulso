# Código de conduta

Este projeto segue os princípios do
[Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Em resumo

Queremos que participar do Pulso seja uma experiência respeitosa para todos, independentemente
de idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de experiência,
nacionalidade, aparência, religião ou orientação sexual.

**Esperado:** gentileza e empatia, respeito a opiniões diferentes, críticas construtivas dadas e
recebidas com boa vontade, foco no que é melhor para o projeto e para quem o usa.

**Não aceito:** linguagem ou imagens sexualizadas, insultos, ataques pessoais ou políticos,
assédio público ou privado, divulgação de informações pessoais de outras pessoas sem
permissão, e qualquer conduta inadequada num ambiente profissional.

## Aplicação

Quem mantém o projeto pode editar ou remover comentários, commits, issues e pull requests que
violem este código, e bloquear temporária ou definitivamente quem o descumprir.

Para relatar um comportamento inadequado, abra uma issue ou, se o assunto for sensível, entre em
contato com o mantenedor pelo perfil no GitHub
([@vinnyzera-ntc](https://github.com/vinnyzera-ntc)). Todos os relatos serão tratados com
discrição.
